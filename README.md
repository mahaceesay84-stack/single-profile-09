# 👤 Single Profile Card Component

A responsive, pixel-perfect social profile card component built as a frontend challenge.

🔗 **Live Demo:** [mahaceesay84-stack.github.io/single-profile-09](https://mahaceesay84-stack.github.io/single-profile-09/)

---

## ✨ Features
- **Pixel-Perfect Styling:** Faithful implementation of card layouts, typography, and color palettes.
- **Fully Responsive:** Adapts cleanly across mobile, tablet, and desktop screens.
- **Modern CSS:** Uses CSS custom properties, flexbox, and smooth hover states.
- **Fast & Lightweight:** Pure HTML and CSS with zero external library dependencies.

---

## 🛠️ Tech Stack
- **HTML5** — Clean, semantic markup
- **CSS3** — Modern styling, Flexbox, media queries

---

```bash
git clone https://github.com/mahaceesay84-stack/single-profile-09.git
```
